ユーザー詳細CSVの登録タイミング

受講者の生年月日・住所・電話番号などをkintoneに登録します。修了証の発行前に必ず実施してください。

  1. 受講申し込みシステムからユーザー詳細CSVをダウンロード（Shift-JIS形式）
  2. 「ユーザー詳細CSVをkintoneに登録」をクリックして専用画面を開く
  3. 「👤 ユーザー詳細CSV」タブを選択
  4. CSVファイルをドラッグ＆ドロップ
  5. 「kintoneに登録する」ボタンを押す
  6. 登録完了後、kintoneで生年月日が入っているか確認
💡 生年月日はkintoneの修了証発行に必要です。研修終了後・修了証発行前に登録してください。
👤 CSVアップローダーを開く

振替登録フォームを開く

欠席した受講者の振替出席を登録します。

  1. フォームを開く（下のボタンをクリック）
  2. STEP 1：欠席した日付を選ぶ
  3. STEP 2：受講者の名前を選ぶ
  4. STEP 3：振替先の日付を選ぶ
  5. 「内容を確認して登録」→「登録する」で完了
💡 修了済み・振替済みの受講者は自動で非表示になります。
📝 振替登録フォームを開く
📋

登録済み振替一覧

これまでに登録された振替記録を確認・削除できます。

  1. フォームを開く（下のボタン）
  2. ページ下部の「登録済み振替一覧」を確認
  3. 削除する場合は「削除」ボタンを押す
⚠ 削除は元に戻せません。慎重に操作してください。
📋 フォームを開いて一覧を確認

動画視聴CSVを取り込む

LMSからダウンロードした user-learning-lesson.csv を取り込みます。

  1. LMSにログインしてCSVをダウンロード（Shift-JIS形式）
  2. フォームを開く（下のボタン）
  3. 「動画視聴 CSV 取り込み」のエリアにファイルをドラッグ
  4. 「取り込む」ボタンをクリック
  5. 「○件を書き込みました」と表示されたら完了
💡 取り込むたびに上書きされます。最新のCSVを使用してください。
🎬 フォームを開く

自動処理の実行ログを確認

GitHub Actionsでエラーが出ていないか確認します。

  1. GitHubにログイン（bestwaycare）
  2. 「koudouengo-attendance」リポジトリを開く
  3. 「Actions」タブをクリック
  4. 最新のワークフロー実行をクリック
  5. 緑のチェック ✅ = 正常、赤の × = エラー
  6. エラーの場合はログ詳細でエラー内容を確認
⚠ 赤いエラーが続く場合はログを確認して担当者に連絡してください。
⚙️ GitHub Actionsを開く
🔐

Secrets（認証情報）を更新

Gmailのパスワードなどを変更した場合に更新が必要です。

  1. GitHubにログイン（bestwaycare）
  2. 「koudouengo-attendance」→「Settings」
  3. 「Secrets and variables」→「Actions」
  4. 更新したいSecretの鉛筆アイコンをクリック
  5. 新しい値を入力して「Update secret」
💡 設定されているSecret一覧：
GOOGLE_CREDENTIALS_JSON / GMAIL_ADDRESS
GMAIL_APP_PASSWORD / EMAIL_RECIPIENT
🔐 GitHub Secretsを開く
🚀

フォームを再デプロイ

フォームを更新した後は再デプロイが必要です。

  1. GASエディタを開く（下のボタン）
  2. 更新したファイルを貼り付けて ⌘S で保存
  3. 右上「デプロイ」→「デプロイを管理」をクリック
  4. 鉛筆アイコン（✏️ 編集）をクリック
  5. バージョンを「新バージョン」に変更 ← 重要！
  6. 「デプロイ」ボタンをクリックして完了
⚠「新バージョン」を選ばないと変更が反映されません。
✏️ GASエディタを開く

💡 研修2日目から7日以内に研修修了日が自動入力されます。修了証発行（「修了証発行したか」→済）はkintoneで手動設定してください。

修了証を発行する

kintoneで「修了証発行したか」を「済」に変更して修了証を発行します。

  1. 振替登録が全員完了しているか確認
  2. 研修修了日が自動入力されているか確認（毎朝8時に自動入力）
  3. kintoneを開き「修了証チェックビュー」を表示
  4. 対象受講者の「修了証発行したか」を済に変更
⚠ 振替登録が残っている受講者は発行しないでください。先に振替登録を完了させてください。
🏢 kintone 修了証チェックビューを開く

スプレッドシートを開く

受講者データ・振替データが格納されています。

  1. Googleスプレッドシートを開く（下のボタン）
  2. 「行動援護」シート：受講者の申し込みデータ
  3. 「振替データ」シート：振替登録の記録
  4. 「動画視聴」シート：動画視聴の進捗データ
⚠ 行動援護シートのデータを誤って削除しないよう注意してください。自動処理のデータソースです。
📊 スプレッドシートを開く

新しいコースを追加する

新しい研修コースの申し込みデータをスプレッドシートに追加します。

  1. Googleスプレッドシートの「行動援護」シートを開く
  2. 申し込みフォームのデータを貼り付け
  3. コース名の形式を確認：「○月○日○日（曜）」
  4. 例：「5月20日27日(水)」「6月8日22日(土)」
  5. 保存すれば次回の自動処理で読み込まれる
⚠ コース名の日付形式が違うと出席簿が生成されません。形式を正確に入力してください。
📊 スプレッドシートを開く

サービスアカウント認証情報

Google Cloud のサービスアカウントキーの確認・再発行手順です。

  1. Google Cloud Console にログイン
  2. プロジェクト「koudouengo」を選択
  3. 「IAM と管理」→「サービスアカウント」
  4. 「attendance-bot」のアカウントを選択
  5. 「キー」タブ →「鍵を追加」→「JSON」でDL
  6. GitHub Secrets の GOOGLE_CREDENTIALS_JSON を更新
⚠ キーの再発行後は旧キーを削除し、GitHub Secretsも必ず更新してください。
🔑 Google Cloud Consoleを開く

修了者名簿を生成する（大阪府提出用）

大阪府への年次提出用「修了者名簿（様式第12号）」を生成します。
生成後、staff@e-bestway.net にExcelファイルが届きます。

💡 毎年5月1日に自動実行されます。
それ以外のタイミングで必要な場合は下のボタンで手動実行できます。
  1. 下の「今すぐ生成」ボタンをクリック
  2. 2〜3分後に staff@e-bestway.net にExcelが届く
  3. 所在地（番地）・法人名を確認・修正する
  4. 大阪府に提出する
⚠ 自動入力できない項目：
・所在地：都道府県のみ。番地まで補完してください。
・法人名：事業所名を流用。正式な法人名に修正してください。
・生年月日：kintoneに登録済みの場合のみ入力されます。
✏️
